# Specimen

`index.html` is generated by `scripts/specimen.mjs` of the design-system skill - never edit it. It is
the one page a human approves and a designer reviews (open points, roles, recipes, components in
every mode and brand, references); `--pdf` prints it once per mode, `--fragment` writes it without
the document skeleton for a host that adds its own. How the page dresses itself comes from
`system.json` `site` (roles, radius, type, inlineFonts - see the script header).

When a human has looked at it in light, dark and every brand and approved it, write
`APPROVED.md` next to it (template: the skill's `references/approved-template.md`). No screen may be
drawn from the system before that file exists.
